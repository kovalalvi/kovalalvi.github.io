Aleksandr Kovalev

I build AI models for intracortical brain-computer interfaces and run closed-loop experiments with an implanted participant.

PhD student with Eduardo Fernández at Universidad Miguel Hernández, Spain. Our participant is blind and has a Utah array in primary visual cortex. I write the stimulation software, design protocols, run sessions and analyze the data. Research: self-supervised learning on neural data, real-time decoding, modeling cortical stimulation.

Before: co-founder of ALVI Labs (EMG control for hand prostheses) and computer vision engineer. 3rd place in the NeurIPS 2025 LibriBrain competition (speech detection from MEG). Physics at Moscow State University, cognitive neuroscience at HSE.
